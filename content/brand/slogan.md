# Dr.Nature Slogan（P1-04）

狀態：推薦版，等 Aki 在閘門 G5 裁決。品牌故事與語調指南見 [story.md](story.md)。合規依據見 [docs/compliance/claims.md](../../docs/compliance/claims.md)。全文已跑過 `node scripts/claims-lint.mjs`。

**分數怎麼來的。** 三位評審沒有替 Slogan 個別打分。下面的「平均分」是這句 Slogan 所屬版本的評審平均總分（六項，滿分 60；見 story.md 評分表）。每位評審另外選了一句「最佳 Slogan」，另列票數。改寫過的句子，評審沒有看過改寫後的版本，所以分數與票數都屬於原句。

## 一、三個候選

### 候選一：少說一點，說準一點。
- **English**：Say less. Say it exactly.
- **出處**：A｜研究者的克制
- **平均分**：45.83／60（A 版）；最佳 Slogan 1 票（評審二）。評審一另外建議把它當內部語調座右銘，或品牌頁 H1。
- **為什麼**：把「克制」直接寫成對讀者的承諾。句中沒有功能、品名或數字，所以 G2 品名怎麼定、U-07／U-08 何時到位，都不用改。三款（包含母嬰方向）都能共用。三位評審都沒有對這句提出風險。
- **弱點**：講的是品牌自己，不是買家（評審三）。用副句補（見第三節）。

### 候選二：看得懂，查得到。
- **English**：Plainly written. Easy to check.（原英文 "Fully checkable." 依評審三建議改寫，拿掉絕對式的 Fully。）
- **出處**：C｜誠實的標籤
- **平均分**：44.17／60（C 版）；最佳 Slogan 1 票（評審三）
- **為什麼**：對家庭讀者給兩個具體承諾：用字白話，項目可以自己查。夠短，放得進小卡一角或團購圖卡。
- **風險與處理**：「查得到」是絕對式承諾。目前菌種、菌數、原產地與製造廠還在等 U-07、U-08，也沒有公開的查證頁（評審二、三）。**啟用條件**：官網的標示頁上線（小卡與標籤上的 QR code 指向它，列出菌種名稱、有效日期等法定標示項目），而且 U-07、U-08 的資料都已填入。條件達成前不得使用。

### 候選三：先讀標籤，再決定。
- **English**：Read the label, then decide.
- **出處**：改寫自 C 的「我們只說標籤上有的。／We say only what the label says.」
- **平均分**：44.17／60（C 版，原句的分數）；原句獲最佳 Slogan 1 票（評審一）
- **為什麼**：保留 C 的核心概念「標籤就是品牌」，但把對品牌自己的絕對保證，改成給讀者的一個動作。原句的問題是，只要文案寫到價格，或寫了標籤上沒有的任何一句，它就不再成立（評審二）；這句永遠成立。它也對應團購範本的「標示表我放在留言，下單前可以先看」，母嬰家庭讀標籤本來就是該做的事。
- **限制**：這句只適合購買前的接觸點，不適合放在已經買到手的盒內小卡。

## 二、推薦

> **少說一點，說準一點。**
> **Say less. Say it exactly.**

理由：
1. **三句中唯一沒有風險、也不需要啟用條件的一句。** 候選二要等標示頁與 U-07、U-08；候選三是改寫句，評審沒有看過。
2. **不依賴任何未定事項。** 沒有品名、功能、數字或研發長，G2、U-07、U-08、U-12 的結果都不影響它。
3. **和推薦故事是同一句話。** 它就是精神支柱「克制」的口語版，品牌頁、首屏、小卡講的是同一件事。
4. **最符合 Aesop 式的調性**：短、安靜、不推銷。評審二（最重合規的一位）選它為最佳。

補弱點：評審三指出它講的是品牌，不是買家。所以購買前的接觸點搭配副句「先讀標籤，再決定。」；標示頁上線、U-07、U-08 到位後，副句可以換成「看得懂，查得到。」。主句、副句一起用，比單句好記（評審三）。

## 三、使用規則

### 用在哪裡
- **主句「少說一點，說準一點。」**：官網首屏或品牌頁 H1、品牌小卡、外盒的品牌面（側面或底部，位置由 DESIGN 決定）、LINE 官方帳號的品牌介紹、名片、對外簡報封面。
- **副句「先讀標籤，再決定。」**：購買前的接觸點，包括團購圖卡、商品頁標示表上方、LINE 圖文選單的商品入口。
- **副句「看得懂，查得到。」**：只在啟用條件達成後使用（見候選二），而且旁邊一定要附通往標示頁的連結或 QR code。

### 怎麼用
- 逐字使用，不改字：不寫「說少一點」「少說點」，也不加「我們」。中文保留兩個逗號與句號。
- 中英並列時中文在上，英文兩句不拆開。
- 不加驚嘆號、表情符號或引號裝飾。字級、字重與版面位置由 DESIGN 決定，需要時開單。
- 團購主可以照原句轉述；合作內容開頭仍要標「合作」或「廣告」。
- 不拿來當品名、系列名或產品副標。

### 永遠不要搭配
1. **功能例句**（幫助消化、調整體質等）：不放在同一個視覺區塊或同一行，免得讀成「話少，但效果準」。
2. **研發長的姓名、照片或學歷**：不放在同一區塊，免得讀成研發長背書。
3. **任何暗示還有作用沒說的話**，例如「其他的不能說」「懂的人就懂」「吃了就知道」。
4. **研究、實驗、數據的字眼與意象**：量筒、試管、白袍、「博士」稱號。
5. **最高級與保證**：最準、保證、第一。「說準一點」是我們對自己寫字的要求，不是對產品的保證。
6. **見證、心得、名人、排名、銷量。**
7. **折扣、倒數、限時、搶購。**
8. **換季、浴室或「伸手就拿得到」的擺放情境**（理由見 story.md 語調指南「不要」第 9 條）。

## 四、未入選的句子

| 句子 | 出處 | 不入選的原因 |
|---|---|---|
| 查證過，才寫上去。 | A | 承諾了還不存在的查核流程；可能被讀成產品經過檢驗（評審一、二） |
| 日常，有刻度。／A daily measure. | A | 英文會被讀成「每日劑量」，建議食用量還在等 U-08（評審二） |
| 日常，是最安靜的儀式。 | B | 「儀式」是常見保健用語，也撞名國外同業品牌；辨識度低 |
| 順著季節，日子如常。 | B | 換季意象加上 SKU-C 原本的方向，可能被讀成功效暗示（評審一、二、三） |
| 為每一天，留一個位置。 | B | 和 B 的擺放場景綁在一起，保存條件（U-08）未定前不用 |
| 我們只說標籤上有的。 | C | 絕對式；文案一寫價格就不成立。已改寫為候選三 |
| 少一句形容詞，多一行標示。 | C | 不當 Slogan。評審三建議可作品牌頁引言；理由文字裡引用的競品用語只留內部，不對外 |
