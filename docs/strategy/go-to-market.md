## 1. 摘要

**主張（分析）**

前 90 天用 Aki 既有的 tuangou-admin 當主要獲客引擎，但有三條紀律：

1. **團購訂單全部導回官網成交（模式一）。** 品牌直接出貨、開發票，買家成為官網會員，回購與結算資料都在本站。
2. **團購只送贈品，不降現金價。** 團購的現金價就是官網公開的 3 入組價。
3. **團購贈品只在全品牌統一的「檔期窗口」出現。** 每 3 週一個 14 天窗口，中間一週空窗，所以「限時」是真的限時。

這樣可以同時拿到速度、價格紀律和第一方資料。

**三根支柱**

| 支柱 | 做法 | 依據 |
|---|---|---|
| 速度：團購引擎 | 上線當週（W1）就開第一個窗口。窗口內同時開團上限 6／12／18／24 團（假設，依出貨與巡檢能力調整），90 天累計目標 ≥ 40 團次（假設）。歸因用「團主專屬碼＋UTM → 訂單 metadata → 手動匯出 GMV → tuangou 結算（`gmv_source=manual`）」，**不必等 P9**。 | 〔計畫 §4〕〔計畫 P5-05、P8-06、P9-03 口徑〕 |
| 紀律：價格 | 公開價只有兩個：單瓶 NT$1,150、3 入組 NT$3,150（每瓶 1,050）。會員 2 瓶以上每瓶 1,035，不公開刊登。團購＝3 入組 3,150 加贈品（市值 ≤ NT$750）。任何疊加後**每瓶現金實付 ≥ 1,035**，由 P5-05 整合測試擋。「定價＝成交價」，不虛標原價。 | 1,150〔市B-1〕；其餘價格為假設；原價與限時規則〔查 §5〕 |
| 資料：放大 | 貨本（COGS）未知前，廣告預算是 0。W7 起依損益兩平 MER 閘門逐週釋出（以 COGS 上限計：單瓶 2.74、3 入組 2.37〔計〕）。電商平台 W6 詢價、W10 決策、最早 W12 上一個平台。 | 50% 毛利經驗法則〔市E-4；[25]〕 |

**擋住定案的三個未知**

- **每瓶貨本（COGS）。** 依「毛利率不到 50% 不建議做電商」〔市E-4；[25]〕：3 入組每瓶貨本上限 500 元；團購組「3 瓶貨本＋贈品成本」上限 1,500 元〔計〕。建議新增 U-15，由 Aki 提供貨本、首批產量、贈品成本。
- **每日食用量（U-08）。** 決定回購窗、LINE 提醒時點，也決定 SKU-C 能溝通的族群。
- **團主接受率與每團訂單數。** market.md 沒有團購轉換統計〔市E-5〕〔市E-7〕。W3 用窗口 1 的實績重訂所有目標。

## 2. 目標與假設

### 2.1 目標

**老闆目標**〔計畫 §1〕：以最快速度搶占台灣電商與團購保健品份額。

**90 天可驗收的目標**（全部是假設，W3、W6 各校準一次）：

- 團購累計 ≥ 40 團次，而且每一團的合規事件都是 0。
- 付款會員數：W3 用窗口 1 實績設基準。
- 單瓶首購者在第一回購窗內的回購率 ≥ 20%。
- MAP 未處理事件 0，結算差異 0。
- 各方案毛利率 ≥ 50%〔市E-4；[25]〕。

**刻意不設的目標**：品牌市占。公開的尼爾森或凱度品牌市占數據查不到〔市A-8〕，設了也量不到。

### 2.3 判斷（分析）

1. **新品牌缺的是信任，不是流量。**
   - 品牌數在見頂的市場裡增加超過六成（計：1,500 ÷ 914 ≈ 1.64）〔市A-5；[4]〕。
   - 有競品取得查驗登記〔市B-2〕，Dr.Nature 很可能沒有〔市・意涵 3〕，文案只能用一般食品的官方例句（[claims.md](../compliance/claims.md) §2）。
   - 團主的個人信用，是新品牌最快能借到的信任。
2. **分潤是成交後才付的變動成本，廣告是先付後看。**
   - 上市初期轉換率未知，用變動成本試錯比較安全。
   - 但 [22] 的分潤率和 [23] 的「廣告成本至少占訂單 30%」是兩篇文章、兩種口徑，**不能拿來直接比較哪個比較便宜**。
3. **團購最大的副作用是價格外流。**
   - 如果團購用現金折價、天天都有團，團購價就會變成實際的公開價，官網價等於虛標（評審指出的 A 案結構問題）。
   - 所以本案團購只送贈品、走窗口制、導回官網，這和〔市・意涵 7〕「用專屬組合或贈品，不要直接降單價」一致。
4. **團購優先本身是待驗證的賭注。** 查不到靠團購放大的保健品牌個案〔市E-7〕，所以設了 W3、W6、W9、W12 四個檢查點和停損條件（§5.3）。
5. **平台先詢價再決定。**
   - 流量趨勢：蝦皮下滑、酷澎成長、momo 份額最大〔市F-1、F-2、F-4〕。
   - 但保健品類由誰主導未驗證，費率也多數未驗證，所以先取得書面報價〔市・意涵 10〕。

### 2.4 時間定義

- **T0：** 首批「標示合規的成品」入庫、可以寄樣的那一天。沒有成品就不能寄樣，也就不能招商。
- **D0：** 正式上線日，也就是閘門 G7（G-LAUNCH 清單**全綠**，不接受部分過閘）〔計畫 §5〕。
- **W1：** D0 所在的那一週。W1–W13 是 90 天。
- **前置條件：** 招商到開團需要約 4 週〔Runbook：D14 起開團，加上寄樣與體驗時間；4 週為假設〕，所以要 **T0 ≤ D0 − 4 週**。
  - 如果成品太晚到，D0 仍照 G7 上線，第一個團購窗口順延到 T0＋4 週之後的第一個窗口。
  - G7 沒過，就不向團主承諾檔期；寄樣照常進行。整體時程順延，不壓縮驗收。
- 印刷與代工的交期由供應商決定〔計畫 §9〕，所以本文只用相對週次。

### 3.1 團購／KOL（主引擎）

**模式一「導流到官網」是 90 天內唯一的模式（分析）**

- **成交流程：** 團主貼文附專屬連結（帶 UTM）和專屬碼 → 買家在官網下單 → 品牌直接出貨（全館免運，〔計畫 A6〕）→ 綠界開立發票（P4-06）。
- **好處：**
  - 買家變成會員，回購資料拿得到。
  - 團主不囤貨，就沒有低價流貨到平台的源頭。
  - 商品頁文案由品牌控制，合規可控。
- **代價：** 習慣自己收單的團主（例如用愛+1 這類整單機器人〔市E-6；[26]〕）可能不接。這是有意的取捨，W13 再檢討。
- **模式二「團主自收單、品牌批貨」90 天內不採用。** 買家資料會留在團主端，價格外流也難控。若日後要開，要另訂批價與 MAP 條款，並先由顧問確認轉售價格限制的法律界線（§4.6）。

**歸因與結算：不必等 P9（從 C 案移植）**

| 步驟 | 做法 | 系統 |
|---|---|---|
| 1 | 每位團主一組專屬碼。碼綁定該窗口的 campaign，有起訖時間與預算上限 | P5-05（Medusa 促銷本身沒有起訖時間，限時要靠 campaign〔查 §3〕） |
| 2 | 團主連結帶 `utm_source=tuangou&utm_medium=kol&utm_campaign=<團主 slug>`（提案，需和 DigiAds 慣例對齊） | P8-06 |
| 3 | 歸因規則：有用團主碼 → 歸該團主；沒用碼但同一工作階段帶該團主 UTM → 歸該團主；一張訂單只歸一位團主 | 訂單 metadata |
| 4 | 依 P9-03 口徑（已付款、扣退款、不含運費）匯出 `{kol, gmv, orders}` | P9 完成前用後台訂單匯出加比對腳本；口徑相同 |
| 5 | `POST /api/settle/runs/<id>/gmv`（`gmv_source=manual`）→ 對帳單 → 撥款 | tuangou-admin〔計畫 §4〕 |
| 6 | 頭部團主在 P9 完成後升級為 `/s/<slug>` 分潤賣場 | P9-01、P9-02、P9-04 |

結算時點：每位顧客自收受商品起有 7 日解除權〔查 §5，消保法 §19〕。所以每個窗口要等最後一筆訂單收貨滿 7 日後才結算，實務上約在窗口結束後 2–3 週（假設，含超商取件時間）。分潤以含稅或未稅 GMV 計算、撥款期限，都待 Aki 決定（§8）。

**主打順序（分析）**

- **SKU-A 先上。**
  - 品名風險「低～中」（naming-proposal）。
  - 可用的官方例句最多：幫助消化、使排便順暢、改變細菌叢生態（claims.md §2）。
- **SKU-C 官網上架；團購與廣告要等兩件事都完成才開放，最早窗口 3（W7）：**
  - U-08 回覆膠囊能否打開沖泡、建議年齡下限。
  - 孕產方向的團主完成合規訓練。

  開放後只對**孕產期本人**溝通，未確認前不對嬰幼兒溝通。原因：該族群常用的說法多半是禁用詞（claims.md §1、§3），而且有查驗登記的競品已在這個市場〔市D-1、D-2；[6][14]〕〔市・意涵 5〕。
- **SKU-B：G2 決定路線甲或乙之前，只在官網上架，不進團購、不投廣告，也不放進任何組合。** 一般食品沒有眼睛相關的合法說法〔法 A1〕。

**團主分層與排除**

- 分層與分潤見 §4.5。
- 主力是「中型團主」：粉絲 1 萬以上、還沒有固定團購報價表的帳號。〔Runbook〕的名單規則是「不用 bio 含團購當條件」，因為那群人已有報價表。
- 大團媽只回應對方主動詢價。
- **招商排除：**
  - 以醫師、營養師身分背書功效的帳號（claims.md §4；〔法 A5；[5][23]〕）。
  - 主打疾病或症狀內容的帳號。
  - SKU-C 開放前，不招母嬰帳號。
- **名單閘門多加一道（從 C 案移植）：** 用 `scripts/claims-lint.mjs` 試掃候選團主近期公開的保健團貼文，過往違規多的不收。

**招商流程：照 Runbook，不另訂**

流程：五把鑰匙 → D0 品牌建檔（P8-08）→ D1 名單三閘門 → 招商信 → 收件 → 寄樣 → 關懷與回訪 → 開團 → 結算。關鍵規則〔Runbook〕：

- 第一封信不寫分潤數字，唯一的 CTA 是收件地址或 LINE。
- 名單抽驗 20 筆，錯 3 筆就整批退回。
- 收件資料完成到寄出 ≤ 2 個工作天。
- 寄達後第 5 個工作天關懷、第 7 個工作天回訪。

## 4. 價格架構與團購價政策

### 4.1 原則（分析）

1. **定價＝成交價。**
   - NT$1,150 是真實售價，不虛標「原價」再打折。
   - 法規依據〔查 §5，公平交易法 §21、公平會處理原則〕：原價須確有以該價格販售的事實；限時須明示期間並到期恢復。
   - 對外只寫「官方定價 NT$1,150」。
2. **優惠只用三種形式：** 組合（3 入）、贈品、會員權益。不直接降單瓶價〔市・意涵 7〕。
3. **團購的現金價＝官網公開的 3 入組價。** 團購只多贈品，所以團購貼文上的價格本身就是公開價，不會把官網價變成虛標。
4. **一條現金地板：** 任何促銷、等級價、團主碼疊加之後，每瓶現金實付 ≥ NT$1,035（官方價的 90%）。系統擋，不只靠人工巡檢。
5. **不倒掛：** 團購的每瓶現金價（1,050）不得低於會員回購價（1,035），回購會員永遠不會比第一次透過團購買的人付更多現金（修正 A 案的 997 < 1,035）。
6. **優惠不疊加：** 團主碼、首購禮、會員回購價三擇一。Medusa 的疊加行為 `TODO(需查證)`，由 P5-05 的整合測試確認。
7. **每一種方案都要先過毛利 50%**〔市E-4；[25]〕，再看分潤與通路費後的貢獻。

- **COGS 門檻：**
  - 3 入組每瓶貨本要 ≤ 500 元。
  - 團購贈品組要「3 瓶貨本＋贈品成本 ≤ 1,500」。例如贈品成本 150 元（假設）時，每瓶貨本要 ≤ 450。
  - 超過的話，依序調整：降贈品成本 → 調低分潤上限 → 調整 3 入組價。
- **分潤試算：** 分潤每增加 5 個百分點，團購贈品組每單少 157.5 元，等於每瓶少 52.5 元（計）。
- **金流試算：** 金流若是 3.0%（假設，用來壓力測試；market.md 只有第三方說法「藍新 2.8% 起、LINE Pay 3%」〔市G-2〕，而且未驗證），單瓶每單少 9.2 元，3 入組每單少 25.2 元（計）。
- **手續費營業稅：** 2.2% 是未稅費率〔市G-1；[34]〕，手續費本身另有 5% 營業稅，相當於交易額的 0.11%（計）。能否當進項稅額扣抵，`TODO(需查證)`，請會計確認。
- **損益兩平 MER（以 COGS 取上限的最差情境）：**
  - 單瓶：可用於獲客 ＝ 967.8 − 547.6 ＝ 420.2 → MER ＝ 1,150 ÷ 420.2 ≈ 2.74。
  - 3 入組：2,828.6 − 1,500 ＝ 1,328.6 → MER ＝ 3,150 ÷ 1,328.6 ≈ 2.37。
  - 會員 2 瓶：1,823.8 − 985.7 ＝ 838.1 → MER ≈ 2.47。

**規則**

- **窗口長度：** 每個窗口 14 天；每位團主的團期 ≤ 10 天〔市E-3；[24]〕，而且在窗口內。窗口之間至少空 7 天（假設）。
  - 這樣「限時」在全品牌層級也是真的：空窗期任何地方都拿不到團購贈品，符合「限時須明示期間並到期恢復」〔查 §5〕。
  - 這修正了評審指出的「多團輪流讓『只開 10 天』失去意義」。
- **同一位團主：** 每兩個窗口最多開一次，約間隔 6 週（假設）。目的是避免同一群粉絲疲乏。
- **同時開團上限：** N ≤ min（每日可出貨單數 × 窗口天數 ÷ 每團預估訂單數，每日可巡檢團數）。上表的 6／12／18／24 是假設，W3 依實際出貨與巡檢能力重訂。
  - 出貨還要守 C2C 寄件期限：7-11 5 天、全家 6 天、萊爾富 7 天〔查 §2〕。
- **上限與目標：** 90 天上限合計 60 團次，KPI 目標 ≥ 40（假設，約上限的三分之二）。
- **空窗期：**
  - 團主連結仍可用公開價下單（無贈品）。訂單依 UTM 歸因，照該團主的基本分潤計（假設；W10 決定是否保留）。
  - 團主碼在空窗期失效（campaign 起訖）。
- **團主碼：** 綁定窗口 campaign 與預算上限（P5-05）。
  - 預算超支時，購物車仍可能帶上折扣，到結帳才擋〔查 §3〕。所以每個碼的預算要預留餘裕，並在後台監看。
- **贈品觸發：** 用 Medusa「買 X 送 Y」（buyget）觸發贈品 variant 是否可行，`TODO(需查證)`，由 P5-05 測試確認。不可行時的退路：依團主碼在出貨時人工加贈（營運 SOP）。
- **招商槓桿用完的退路（分析，依序）：**
  1. 贈品升級（市值上限 750 以內）。
  2. 中型團主分潤 15% → 20%。
  3. 擴大名單層級。
  4. **只有 Aki 核准後**，才考慮團購現金價，而且每瓶不得低於 1,035。

### 4.6 最低公開標價（MAP）紀律

**定義（政策）**

任何公開可見的刊登，所呈現的每瓶現金價都不得低於下表。公開可見包括：團主貼文、廣告、平台商品頁、比價網、LINE 公開貼文。

| 品項 | 每瓶現金價下限 |
|---|---|
| 單瓶 | 1,150 |
| 多入組 | 1,050（3 入組 3,150） |
| 會員回購價 1,035 | 不得公開刊登具體數字，只在登入後與回購會員推播中出現 |

**寫進團購合作條件的禁止事項**

1. 自行加碼折扣，或把分潤退給粉絲（現金回饋、退傭）。
2. 寫出低於上表的單價。
3. 窗口外張貼團購贈品條件。
4. 在任何平台轉售。
5. 寫「限定」「只開○天」這類**全品牌層級不成立**的說法。範本只寫「本連結贈品期間 ○/○–○/○」。

**監看（分析）**

- 每週一次，人工搜尋品牌名：FB、IG、蝦皮、露天、momo、酷澎。
- 窗口期間，每天看已登記的團主貼文。每位團主的貼文連結登記在 tuangou-admin。
- 程序寫進新的 `docs/ops/map-monitoring.md`（從 B 案移植）。

**違規處理**

| 次數 | 處理 |
|---|---|
| 第 1 次 | 通知後 24 小時內修正。48 小時未修正，列為「未處理事件」。 |
| 第 2 次 | 取消下一個窗口。 |
| 第 3 次 | 終止合作、停用碼。**已成交的分潤照付**，保住純分潤合作的信任。 |

**法律界線：**

- 原價與限時的規範已有研究〔查 §5〕。
- 「限制他人轉售價格」在公平交易法上的規範，docs/research 沒有來源，`TODO(需查證)`，簽約前請顧問確認。
- 模式一裡團主不持有商品、由品牌直接銷售、品牌自訂售價，這類風險較低（分析）；若改採模式二或平台買斷，條款的可執行性要另外確認。
