# 合規用詞表（所有對外文字必過）

機器可讀規則：[claims.json](claims.json)，由 `node scripts/claims-lint.mjs` 執行。法源與來源編號：[../research/regulatory.md](../research/regulatory.md)。本表是工程守門，不是法律意見。

## 1. 三條底線

1. **產品是一般食品**：不得宣稱或暗示預防、改善、治療任何疾病或症狀；不得出現「健康食品」字樣（未經查驗登記屬刑事責任，健康食品管理法 §6、§21）。
2. **品名也算宣稱**：主管機關會把品名和整體表現合併認定。「過敏康」「護敏」已有裁罰先例 → 任何含「敏」的品名都不用。
3. **研究不等於功效**：研發長的論文與專利（糖尿病、口腔癌、天然物）不得拿來暗示本產品功效；體外或動物試驗不得寫成人體效果。

## 2. 可以用的說法（官方例句，逐字使用）

| 方向 | 可用例句 | 條件 |
|---|---|---|
| 消化、排便 | 幫助消化／幫助維持消化道機能／改變細菌叢生態／使排便順暢 | 一般食品即可 |
| 體質、日常 | 調整體質／調節生理機能／健康維持／營養補給 | 一般食品即可；不可與「過敏」「敏」並列 |
| 孕產 | 產前產後或病後之補養 | 一般食品即可 |
| 視覺 | 有助於維持在暗處的視覺 | **僅限**配方含合規量的維生素 A 或 β-胡蘿蔔素，並寫明「維生素 A 有助於…」 |
| 排便（纖維） | 可促進腸道蠕動／使糞便比較柔軟而易於排出 | **僅限**配方含合規量膳食纖維，並寫明是膳食纖維的功能 |

## 3. 不能用的說法（節錄；完整清單見 claims.json）

便秘、整腸、健胃、壞菌、害菌、殺菌、抑菌、過敏、敏感體質、舒敏、護敏、低敏、免疫、抵抗力、保護眼睛、護眼、顧眼、視力、近視、乾眼、飛蚊、黃斑、藍光、眼睛乾澀、眼睛疲勞、治療、治癒、療效、預防、根治、消炎、癌、糖尿病、降血糖、降血壓、排毒、健康食品、醫師推薦、無副作用、立即見效、有效對抗。

警示（不擋建置，但需 Aki 在 G2 裁決）：晶亮。

## 4. 代言、見證、KOL

- KOL、素人分享、留言都算廣告；違規留言要刪除或隱藏。
- 研發長可以出現，但：只寫查證過的經歷（[../research/cro.md](../research/cro.md)）、揭露與品牌的利益關係、取得書面同意；不穿醫師袍、不稱「醫師」。
- 不使用醫師、營養師背書產品功效。
- 每則合作內容標示「廣告」或「合作」。

## 5. 標示（包裝）必備

依食安法 §22：品名、內容物（益生菌要寫菌種名稱，不可只寫「益生菌」，建議中英文）、淨重／數量、食品添加物、廠商名稱電話地址、原產地、有效日期、營養標示（膠囊用「每一份量＋每日參考值百分比」）、基改原料、過敏原（「本產品含有○○」）、素食標示（若宣稱素食）。有標示菌數者，效期內必須達到。

## 6. 免責聲明（允許清單，逐字）

- 本產品為一般食品，非藥品，不具醫療效能。
- 本產品非健康食品，未經健康食品查驗登記。

以上兩句是 lint 的例外：句子完整且逐字相同時，句中的「醫療」「健康食品」不會被擋。
