# 產品編碼邏輯（P2-02）

機器可讀的商品主檔：[`content/products/catalog.json`](../../content/products/catalog.json)。驗證：`node --test scripts/__tests__/catalog.test.mjs`（已納入 `scripts/test-all.sh`）。

## 1. SKU

格式：`DN-{系列}-{品項}-{規格}[-{包裝}]`，全大寫英數與連字號。

| 段 | 規則 | 例 |
|---|---|---|
| `DN` | 品牌碼（Dr.Nature），固定 | `DN` |
| 系列 | 2 碼英文：`PB`＝益生菌 Probiotics。新系列先在本表登記再使用 | `PB` |
| 品項 | 2 碼數字，系列內流水號，**永不重複使用**（停產的號碼保留） | `01` |
| 規格 | 3 碼數量＋1 碼單位：`C` 膠囊、`T` 錠、`S` 條／包、`G` 公克 | `060C` |
| 包裝（選填） | `X{n}`＝n 入組（如 `X3`）；`TRY`＝體驗包／樣品 | `X3`、`TRY` |

正規表示式：`^DN-[A-Z]{2}-\d{2}-\d{3}[CTSG](-(X[2-9]|X[1-9]\d|TRY))?$`

第一系列：

| SKU | 品項 | 狀態 |
|---|---|---|
| `DN-PB-01-060C` | SKU-A（消化、排便方向） | 名稱待 G2 |
| `DN-PB-02-060C` | SKU-B（原護眼方向） | 名稱與配方路線待 G2 |
| `DN-PB-03-060C` | SKU-C（體質、母嬰方向） | 名稱待 G2 |

多入組（如 3 瓶組 `DN-PB-01-060C-X3`）在 Medusa 以「同一商品的另一個 variant」建立，庫存以 inventory kit 對應 3 個單瓶庫存（P5-05 促銷時實作）。
