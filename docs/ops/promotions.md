# SOP：活動促銷範本（P5-05）

適用：營運（operations）與 Super Admin。程式：`apps/backend/src/lib/promotions/templates.ts`、`POST /admin/promotion-templates`；測試：`integration-tests/http/promotions.spec.ts`。法規查證見 [../research/p4-p5-2026-10-13.md](../research/p4-p5-2026-10-13.md) §3、§5；價格策略見 [../strategy/go-to-market.md](../strategy/go-to-market.md)。

## 1. 四種範本

| 範本 | `template` | 必填欄位 | 效果 |
|---|---|---|---|
| 滿額折 | `spend_threshold` | `min_total_twd`，加上 `amount_off_twd` 或 `percent_off`（二擇一） | 購物車商品金額（含稅、折扣前）達門檻，整筆折抵 |
| 第二件折 | `nth_item` | `product_ids`、`percent_off`（`buy_quantity` 預設 1、`max_discounted_units` 預設 5） | 每買 N 件，下一件打折（同商品數量折扣，不算贈品） |
| 買 X 送 Y | `buy_x_get_y` | `buy_product_ids`、`buy_quantity`、`gift_product_ids`（`gift_quantity` 預設 1、`max_gifts` 預設 1） | 贈品那一行折 100%；贈品要由顧客或前台加入購物車 |
| 免運 | `free_shipping` | （`min_total_twd` 選填） | 運費全免。全館已免運，這個範本給收費的配送方式（例如宅配） |

每個範本都可以加：

- `window: { starts_at, ends_at }`：**限時**。兩端都必填，時間要帶時區，例如 `2026-11-01T00:00:00+08:00`。窗口外的優惠碼可以輸入，但不會折抵。
- `budget: { type: "usage" | "spend", limit }`：**預算上限**。`usage` 是可成立幾筆訂單，`spend` 是總共可折多少元。
- `limit`：這個優惠碼最多用幾次。
- `automatic: true`：不必輸入代碼就自動套用。預設是要輸入代碼，因為團主碼同時用來歸因（go-to-market §1）。

代碼規則：3 到 32 個大寫英文、數字、`-` 或 `_`，例如 `GL-AMY-W1`。

範例（營運帳號，後台登入後以 API 呼叫；前台管理介面於 P7 之後再做）：

```json
{ "template": "spend_threshold", "code": "SPEND3000", "name": "滿 3,000 折 200",
  "min_total_twd": 3000, "amount_off_twd": 200,
  "window": { "starts_at": "2026-11-01T00:00:00+08:00", "ends_at": "2026-11-14T23:59:59+08:00" },
  "budget": { "type": "usage", "limit": 300 } }
```

## 2. 系統會擋的事

| 情況 | 結果 |
|---|---|
| 送的贈品是**不同商品**，價值超過購買金額的一半（購買金額未滿 100 元時，上限 50 元） | 建立時拒絕（贈品贈獎額度辦法 §3）。以「最便宜的購買規格 × 數量」對比「最貴的贈品規格 × 數量」計算 |
| 範本裡的商品 ID 不存在 | 建立時拒絕；不然這個優惠永遠不會生效 |
| 優惠疊加後，**每瓶實付低於 NT$1,035**（含稅、所有折扣後，DN-PB- 開頭的 SKU 平均） | 結帳時拒絕，顧客看到「優惠合併後超過本店的折扣上限，請移除一個優惠碼後再結帳。」。手動在後台建立的促銷也一樣會被擋 |
| 預算用完 | 新的購物車不會折抵。**已經套用折扣、還沒結帳的購物車**，結帳時會被拒絕，前台要顯示訊息並請顧客移除代碼 |

每瓶 1,035 元的下限是 go-to-market §1 的提案（等於 1,150 元打 9 折），**還沒有經 Aki 核准**。要調整時，改 `apps/backend/src/lib/pricing/price-floor.ts` 的一個數字，並另外提交。同款「買二送一」會讓每瓶平均降到 767 元，所以會被擋；要做這種活動，必須先由 Aki 決定調整下限。

## 3. 文字與法規（系統擋不住，靠人工）

1. **原價**：只能標示真的用那個價格賣過的價格。官網價格就是 1,150 元，不另外標一個較高的「原價」（公平交易法 §21；研究 §5）。
2. **限時**：活動頁面與貼文要寫出起訖日期與時間；到期後恢復原價。不要長期掛著「限時」。
3. **第二件折**：同商品的數量折扣不算贈品（公平會 105.05.12 令）。送**不同**商品才受贈品上限限制。
4. **7 日解除權**：網購的益生菌原則上可以在收到後 7 日內退貨（消保法 §19），拆封也可以退。活動文案不可以寫「拆封不退」或「活動品不退」。
5. **會員訊息也是廣告**：LINE 推播、會員群組提到產品時，同樣受食安法 §28 限制。所有文案要先跑 `node scripts/claims-lint.mjs`。

## 4. 已知限制

- 低於門檻時輸入代碼，系統會接受但不折抵（Medusa 2.21.2 的行為）。前台要提示「未達門檻」。
- 自動取消的未付款訂單（P4-09）**不會**把優惠使用次數與預算還回去（Medusa 2.21.2 限制，研究 §3）。預算型活動要預留一些額度。
- 優惠碼一旦建立，就不能透過範本修改。要改內容，請在後台把舊的優惠停用，再用新的代碼建立。
